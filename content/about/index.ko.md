안녕하세요, 장재혁입니다.

AFINIT에서 Data Engineering 팀을 리딩하고 있습니다. 인도 시장의 핀테크 서비스인 True Balance와 True Credit의 데이터 플랫폼을 수집과 스트리밍부터 저장, ELT, 거버넌스, 모니터링까지 맡고 있고, 설계와 운영, 장애 대응에도 직접 참여합니다.

결제와 대출 데이터를 다루다 보니 파이프라인이 잘 도는지만큼 데이터가 정확한지, 누가 어떤 데이터에 접근하는지를 중요하게 봅니다. 요즘은 AI agent를 새로운 데이터 소비자로 보고, 이들이 통제된 범위 안에서 데이터를 찾고 쓸 수 있는 AI-ready 데이터 플랫폼을 만드는 데 관심이 많습니다.

운영하면서 배운 것들을 틈틈이 기록해보려 합니다.

## Tech Stack

- **Processing:** Spark, PySpark, Flink, dbt, EMR
- **Streaming & CDC:** Debezium, Kafka, Kinesis, NiFi
- **Storage & DW:** S3, Athena, Glue, Iceberg, DynamoDB, OpenSearch
- **Orchestration:** Airflow
- **DevOps & Infra:** Docker, Jenkins, SAM, CloudFormation, Lake Formation
- **Monitoring:** Prometheus, Grafana, CloudWatch, Kibana
- **Cloud:** AWS
- **Languages:** Python, SQL
