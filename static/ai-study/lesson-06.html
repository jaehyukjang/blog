01 / 가볍게 시작3분

합계가 그럴듯해 보이면, 맞을까요?

숫자에도 말투가 붙어요. “정확히 계산했습니다”라는 설명보다 계산 대상과 결과를 확인하는 것이 중요합니다. 오늘은 작은 표라서 직접 확인할 수 있어요. 실제 가계부를 가져올 필요는 없습니다.

오늘의 준비

아래의 가상 생활비 표와 빈 엑셀 시트를 준비하세요. 표에는 실제 결제 정보가 없어요. AI에 파일을 올리지 않고 텍스트로 붙여 넣어도 됩니다.

엑셀이 없다면 계산기로 합계를 확인해도 좋아요. 차트 만들기는 여유가 있을 때만 합니다.

02 / 원리 알아보기7분

먼저, 한 줄이 무엇을 뜻하는지.

1. 행·열·단위를 정하면 해석이 쉬워요.

이 표에서 한 행은 결제 한 건, 열은 일자·분류·금액 같은 속성이에요. 금액 단위는 원입니다. “이 자료에서 한 줄은 무엇인가?”를 먼저 정하면 엉뚱한 집계를 줄일 수 있어요.

빈칸과 0원은 다르고, 같은 금액이 반복된다고 중복 결제인 것은 아니에요. 무엇을 중복으로 볼지 기준이 필요합니다.

2. 표 정리와 계산은 다른 작업이에요.

분류 이름을 통일하거나 특징을 설명하는 것과, 정해진 범위를 합산하는 것은 달라요. 숫자 계산은 계산 도구나 엑셀 수식으로 확인하면 근거가 분명해집니다.

AI가 계산 도구를 썼더라도 행을 빼먹거나 환불을 잘못 처리하면 합계가 틀릴 수 있어요. 도구 사용 여부뿐 아니라 대상 행과 계산 기준도 봅니다.

3. 설명 가능한 합계가 좋은 합계예요.

분류별 합계를 모두 더했을 때 전체 합계와 맞아야 해요. 분류를 바꿔도 결제를 빼거나 더하지 않았다면 전체 금액은 같아야 합니다.

총액과 실제 행 수를 함께 확인하면 누락을 찾기 쉬워요. 숫자에서 패턴을 찾는 것과 소비 습관의 원인을 단정하는 것도 구분합니다. 이 작은 가상 기록만으로 한 달 소비를 판단할 수는 없어요.

03 / 같이 해보기15분

아홉 줄에서 시작하는 숫자 확인.

금액 두 건이 같아도 별개의 결제입니다. 오늘은 데이터를 임의로 삭제하거나 소비를 평가하지 않아요.

복사 버튼은 문장만 복사해요. 사용 중인 AI 대화창에 직접 붙여 넣어 보내주세요.

2. 대상과 계산 기준을 명시하기 · 4분

같은 금액의 두 커피와 두 취미 지출이 빠지지 않았는지 봐요. AI가 실제 계산 도구를 사용할 수 없다면 그 한계를 말하도록 요청합니다.

이 표는 가상의 생활비 기록이야. 한 행은 결제 한 건이고 금액 단위는 원이야.
9건을 모두 유지하고, 같은 금액이라는 이유로 중복 제거하지 마.
전체 건수, 전체 금액 합계, 분류별 건수와 금액 합계를 정리해줘.
계산 도구를 사용할 수 있으면 사용해줘. 사용할 수 없으면 그렇게 밝혀줘.
분류별 합계의 합이 전체 합계와 같은지도 확인해줘. 소비 습관에 대한 평가는 하지 마.

3. 엑셀에서 직접 대조하기 · 5분

표가 A1:E10에 들어갔다면 빈 셀에 =SUM(D2:D10)을 넣어 전체 합계를 확인해요. =COUNTA(A2:A10)은 번호가 있는 행 수를 셉니다.

식비 합계는 =SUMIF(C2:C10,"식비",D2:D10)으로 확인할 수 있어요. 숫자가 한 열에 몰리거나 합계가 0이면 먼저 열 구분과 숫자 형식을 확인하세요.

번호 E7의 금액을 12,000에서 15,000으로 잠깐 바꿔 합계가 3,000 늘어나는지도 볼 수 있어요. 확인한 뒤 원래 값으로 돌려놓습니다.

직접 확인한 뒤, 검산 예시 열기
  • 총 9건, 합계 76,000원. 식비 37,000원, 카페 9,000원, 교통 6,000원, 취미 24,000원.
  • 카페를 식비에 합치기로 했다면 식비는 46,000원, 교통은 6,000원, 취미는 24,000원입니다. 분류를 바꿔도 전체 합계 76,000원은 같아야 합니다.
  • 번호 E7의 금액 12,000원을 15,000원으로 바꾸면 전체 합계는 79,000원입니다. 확인 후 원래 값으로 돌려놓으세요.

4. 분류 하나를 바꿔보고 비교하기 · 3분

카페를 식비에 합쳤을 때 분류별 결과만 달라지고 총액은 같은지 확인해요. 원본을 덮어쓰지 않고 새 요약으로 받아봅니다.

원본 결제 내역은 그대로 두고, 카페를 식비에 합친 새 분류별 요약을 보여줘.
변경 전후의 전체 합계가 같은지 확인해줘.
여유가 있다면 새 분류별 금액으로 막대 차트를 제안하고, 단위를 원으로 표시해줘.
이 9건을 전체 월간 생활비로 확대 해석하지 마.
진행자 메모 · 실습을 도와줄 때
  • 표와 수식은 작은 예제이므로 엑셀에서 직접 확인할 수 있어요. 복잡한 분석 도구를 새로 설치하지 마세요.
  • 한 열로 붙으면 엑셀의 텍스트 나누기에서 탭 구분을 사용하거나, AI에게 각 열을 나눠 보여달라고 요청하세요. 붙여 넣은 위치와 수식 범위가 맞는지 먼저 봅니다.
  • 합계는 76,000원, 9건입니다. 식비 37,000원, 카페 9,000원, 교통 6,000원, 취미 24,000원이에요.
  • 차트는 선택 활동이에요. 합계 확인을 마쳤다면 오늘의 목적은 달성한 것입니다.
