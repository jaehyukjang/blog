01 / 가볍게 시작3분

읽고 끝난 답, 써본 적도 있나요?

추천을 읽는 것과 실제로 체크하는 목록을 쓰는 것은 조금 달라요. 오늘은 대화 끝에 내 손에 무엇이 남을지 먼저 정해봅니다. 예제 대신 취미 계획표나 간단한 모임 안내문을 만들어도 좋아요.

오늘의 준비

메모 앱이나 문서 앱 하나를 열어두세요. 파일 생성 기능이 있다면 사용해도 되지만, 없어도 답을 복사해 저장하면 됩니다. 예제는 혼자 두 시간 정도 외출할 때의 체크리스트예요.

02 / 원리 알아보기7분

완료 기준이 있으면 수정도 쉬워요.

1. 결과물은 사용 장면에서 출발해요.

휴대폰으로 볼지, 종이에 인쇄할지, 다른 사람에게 보낼지에 따라 좋은 모양이 달라져요. “체크리스트 만들어줘”에 “출발 직전 휴대폰으로 볼 것”을 더해보세요.

한 화면에 읽히는 짧은 목록, 체크할 수 있는 항목, 필요한 순서처럼 사용 장면을 말해주면 결과를 판단할 기준이 생깁니다.

2. 먼저 내용, 그다음 표현과 형식.

항목이 틀렸는데 예쁘게 정리해도 쓰기 어렵습니다. 빠진 것과 불필요한 것을 먼저 고치고, 그다음 길이와 순서를 다듬어요.

“더 좋게”보다 “내가 갖고 있지 않은 물건은 빼줘”, “출발 직전에 확인하는 항목을 위로” 같은 피드백이 수정 방향을 분명하게 합니다.

3. 저장하고 열어봐야 끝나요.

AI가 만들었다고 말한 것과 실제 파일이 생긴 것은 다를 수 있어요. 다운로드한 파일이나 복사한 메모를 직접 열어 내용과 형식을 확인합니다.

화면에 잘 보이는 표라도 휴대폰에서는 가로로 길 수 있어요. 내가 사용할 환경에서 한 번 보는 것이 결과물 검토예요.

03 / 같이 해보기15분

출발 전에 딱 보는 체크리스트.

목록의 항목 수를 늘리기보다 실제 외출에 필요한 것을 고릅니다. 사적인 이름·주소·연락처는 넣지 않아도 돼요.

복사 버튼은 문장만 복사해요. 사용 중인 AI 대화창에 직접 붙여 넣어 보내주세요.

1. 사용 장면과 완료 기준 말하기 · 3분

예제의 외출 상황을 자신의 취미나 약속으로 바꿔도 좋아요. 한 번에 많은 기능을 만들기보다 한 가지 결과물을 정합니다.

혼자 두 시간 정도 동네에 외출할 때 쓸 체크리스트를 만들어줘.
휴대폰으로 출발 직전에 볼 거야.
준비할 때 / 문 나서기 직전 두 묶음으로 나눠줘.
체크 항목은 총 8개 이내, 각 항목은 짧은 행동 문장으로 써줘.
특별한 장비나 새 물건을 사는 항목은 넣지 말아줘. 아직 디자인보다 내용에 집중해줘.

2. 내게 안 맞는 항목 바꾸기 · 5분

자기 상황과 안 맞는 항목 하나를 골라 이름을 직접 말해보세요. 예시 문장의 대괄호를 실제 항목으로 바꿉니다.

[내게 불필요한 항목]은 빼줘.
대신 [실제로 자주 잊는 것]을 넣어줘.
내가 수정한 항목 외에는 내용이 꼭 필요한 경우에만 바꿔줘.
중복된 항목이 있으면 합치고, 출발 직전에 볼 순서로 정리해줘.

3. 휴대폰에서 쓰기 편한 형태로 만들기 · 4분

목록에 체크 표시를 붙이고 메모 앱에 복사해보세요. 앱의 체크리스트 기능을 켜면 항목별로 체크할 수 있습니다. AI가 준 네모 문자가 실제 버튼인 것은 아니에요.

확정한 내용을 휴대폰 메모에 붙여 넣기 좋은 형태로 정리해줘.
표 대신 짧은 제목과 한 줄짜리 항목을 써줘.
각 항목 앞에 □를 붙이고, 설명 문단은 빼줘.
끝에 “상황에 맞지 않는 항목은 지워도 됨”을 한 줄로 붙여줘.
이렇게 해도 좋아요
  • 실제 다운로드 파일을 만들 수 있는 환경이라면 텍스트 파일로 저장해달라고 요청해도 좋아요. 링크가 있는지, 열리는지, 내용이 맞는지 직접 확인하세요.
  • 오늘은 메모에 복사해서 이름을 붙여 저장하는 것만으로도 완료입니다.

4. 정말 쓸 화면에서 열기 · 3분

저장한 메모를 열고 실제 출발 상황이라고 생각하며 한 번 읽어보세요. 한 항목이 길거나 뜻이 모호하면 그 부분만 고칩니다. 휴대폰으로 옮기기 어렵다면 맥북 메모에서 먼저 확인해도 좋아요.

이 체크리스트에서 행동이 불분명한 항목이 있는지 확인해줘.
있다면 해당 항목만 더 구체적으로 바꿔줘.
새로운 준비물이나 항목은 추가하지 말아줘.
진행자 메모 · 실습을 도와줄 때
  • “예쁜 디자인”을 먼저 요구하지 않아도 됩니다. 실제로 쓸 수 있는지 확인하는 경험이 목표예요.
  • AI가 수정하면서 잘 맞던 내용까지 바꾸면 “이 항목만 바꿔줘”라고 범위를 좁히는 방법을 보여주세요.
  • 파일 다운로드가 안 되면 메모 앱으로 복사하세요. 도구 문제 해결이 수업의 중심이 되지 않도록 합니다.
04 / 잠깐 생각하기3분
